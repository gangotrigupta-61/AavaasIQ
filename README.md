## 📖 What is AavaasIQ?

**AavaasIQ** is an all-in-one smart management platform built for modern residential societies, apartment complexes, and gated communities.

In most apartment complexes today, daily operations are scattered everywhere: security guards write visitor details in messy paper registers, packages get lost at the gate, residents argue over maintenance dues in WhatsApp groups, and finding a trusted plumber or electrician takes hours.

**AavaasIQ brings everyone together on one easy-to-use digital platform:**
- **Residents** manage their homes, visitors, dues, and complaints from their phone or computer.
- **Society Management (RWA / Committee)** easily tracks finances, notices, and community maintenance.
- **Security Guards** log visitors and parcels in seconds on a simple touch screen.
- **Service Partners** (electricians, plumbers, carpenters) receive local repair requests and serve residents directly.

## 🌟 The 4 Key Portals in Detail

### 🏠 1. Resident Portal — Complete Peace of Mind at Home
- **Digital Guest Passes:** Pre-approve visitors, delivery agents, or cab drivers by creating a quick pass code to avoid long waits at the gate.
- **Parcel Notifications:** Get notified the moment a package arrives at the security gate, and track when it is collected.
- **Maintenance & Dues:** View itemized maintenance invoices, check due dates, and view past receipts.
- **Raise Maintenance Requests:** Report plumbing, electrical, or lift issues in seconds with priority levels and photo attachments.
- **Community Notice Board & Events:** Stay up to date on water shutdowns, festival celebrations, and general body meetings.
- **Trusted Home Services:** Book verified electricians, plumbers, appliance technicians, and carpenters right from your home.
- **Emergency SOS:** Fast one-tap access to the security guard desk, local police, and emergency medical services.

### 🏢 2. Society Management (RWA / Committee) Portal — Smooth Community Administration
- **Community Overview Dashboard:** At-a-glance stats showing total occupied flats, monthly maintenance collections, and open complaints.
- **Resident Directory:** Centralized, searchable records of all owners, tenants, flat numbers, and emergency contacts.
- **Financial Records:** Clear ledger showing who has paid maintenance dues, outstanding balances, and payment proofs.
- **Complaint Management Desk:** Assign resident complaints to maintenance staff or outside vendors and track resolution time.
- **Official Announcements:** Publish urgent alerts, scheduled maintenance notices, or community circulars to all residents in one click.
- **Visitor & Security Audit Logs:** Real-time visibility into who is currently inside the society and historical gate entry records.

### 🛡️ 3. Security Guard Console — Simple, Fast Gate Operations
- **Touch-Friendly Gate Screen:** Built with big buttons and clear forms so guards can log visitors in just a few taps.
- **Pass Verification:** Instantly verify digital entry codes shown by arriving visitors or delivery drivers.
- **Parcel Inwarding:** Quickly log courier packages (courier name, recipient flat) to notify residents immediately.
- **Live Premises Activity:** See real-time counts of visitors currently inside the gates and log departures smoothly.

### 🛠️ 4. Service Partner Desk — Empowering Local Technicians
- **Service Request Pipeline:** View new service bookings requested by society residents (plumbing, wiring, appliance repair).
- **Job Status Management:** Update service progress easily (`Pending` → `Accepted` → `In Progress` → `Completed`).
- **Earnings & Performance:** Keep track of completed jobs and customer feedback.

## 💻 Technical Architecture (For Developers)

For software engineers and technical contributors, here is how AavaasIQ is built under the hood:

### Tech Stack
- **Framework:** [Next.js 16](https://nextjs.org/) (App Router + Turbopack) with React Server Components (RSC) for fast loading.
- **UI Library:** [React 19](https://react.dev/) utilizing smooth transitions and Server Actions.
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) with native CSS variables and dynamic theme switching.
- **Language:** [TypeScript](https://www.typescriptlang.org/) for complete type safety across frontend and backend calls.
- **Database & Auth:** [Supabase](https://supabase.com/) (PostgreSQL) with Row Level Security (RLS) for rock-solid tenant privacy.
- **Realtime Sync:** Supabase Realtime WebSockets for live visitor alerts and ticket updates.
- **Icons:** [Lucide Icons](https://lucide.dev/) for lightweight, accessible vector graphics.

## ⚙️ How to Run Locally

If you'd like to run AavaasIQ on your own computer:

### 1. Clone the repository
```bash
git clone https://github.com/gangotrigupta-61/AavaasIQ.git
cd AavaasIQ
```

### 2. Install dependencies
```bash
npm install
```

### 3. Set up environment variables
Create a `.env.local` file in the main folder and add your Supabase connection details:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your_supabase_anon_key
```

### 4. Start the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your web browser to see the application running!

## 🔒 Security & Privacy by Design

- **Role-Protected Access:** Residents only see their own flat's information; guards only see gate logs; admins manage community affairs; and service partners only see their assigned jobs.
- **Database-Enforced Security:** Every database query is verified with PostgreSQL Row Level Security (RLS), keeping community data private and isolated.
- **No Shared Passwords:** Safe, modern cookie-based session authentication with encrypted passwords.
